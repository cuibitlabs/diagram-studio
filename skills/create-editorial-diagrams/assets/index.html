Example library

31 diagram types in 5 delivery variants — 155 self-contained files. Each opens offline with no build step, no JavaScript unless the diagram is stepped, and no network request.

Generated by scripts/build-examples.mjs from the same engine the studio and the CLI use. scripts/verify-examples.mjs fails the build if any file drifts from it, so an example can never show a skin the code has moved on from.

light
Inline in a document. The canvas follows the drawing.
dark
A separately audited dark palette, not an inverted light one.
full
Title and standfirst drawn on the canvas, for a standalone figure.
slide
Pinned to a 1600x900 stage and centred, so a deck stays consistent.
terminal
Monospace, unfilled shapes, accent carried by stroke. For docs beside code.
